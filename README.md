# G. Poornachandu — Deploy-Ready Portfolio

## Included
- Responsive dark/glassmorphism portfolio
- Resume PDF in `assets/`
- SEO/meta/social tags
- Favicon
- Accessible mobile navigation
- Reduced-motion support
- Scroll reveal animations
- GitHub Pages / Netlify / Vercel compatible static site
- robots.txt and sitemap.xml placeholders

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `poornachandu-portfolio`.
2. Upload every file in this folder (including `assets/`).
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. Save and wait for the Pages URL.
5. Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml` with your real URL.

## Deploy with Netlify
Drag the entire folder into Netlify's deploy area, or connect the GitHub repository.

## Deploy with Vercel
Import the GitHub repository in Vercel. No build command is required; it is a static site.
